✦ PERGUNTAS FREQUENTES

Uma ajudinha
antes de começar?

O que é o Boobot? +

É um aplicativo desktop para você conversar com agentes de IA chamados Boos e trabalhar com eles em projetos de programação e criação.

Os Boos podem modificar meu código? +

Com um runtime configurado e as permissões certas, eles podem ajudar a ler, criar e alterar arquivos. Revise alterações e mantenha seus projetos versionados.

Preciso usar vários agentes? +

Não. Você pode começar com uma única conversa e adicionar outros Boos quando fizer sentido.

Posso usar em outro computador? +

O recurso de hosts permite conexões via rede local, VPN ou SSH. A versão está em beta e ainda precisa de mais testes entre computadores físicos.

Já posso baixar o Boobot? +

Uma versão beta privada para Windows está sendo testada. Ainda não há um download público oficial; acompanhe esta página para a futura liberação.
